# Don't Look, Honey — 關卡通關條件

## 核心數字

| 項目 | 數值 |
|---|---|
| 起始資金 | $10,000 |
| 勝利目標 | $30,000（累計 realized P&L） |
| 需獲利 | $20,000 |

> P&L 跨關卡保留；未平倉部位換關時直接清除（不結算）。

---

## Stage 1 — 家

| 項目 | 內容 |
|---|---|
| 時間 | 300 秒（5 分鐘） |
| 通關條件 | 倒數結束時 realized total ≥ $30,000 → 進入 Stage 2 |
| 失敗條件 | total < $30,000 → TIMEOUT / 被老婆看到 → CAUGHT |
| 老婆轉頭間隔 | 25–30 秒 |
| 盯視時間 | 4–8 秒 |
| QTE | 無 |
| 老婆位置 | 固定右側 |

---

## Stage 2 — 街道

| 項目 | 內容 |
|---|---|
| 時間 | 420 秒（7 分鐘） |
| 通關條件 | 倒數結束時 realized total ≥ $30,000 → 進入 Stage 3 |
| 失敗條件 | total < $30,000 → TIMEOUT / 被看到 → CAUGHT |
| 老婆轉頭間隔 | 15–20 秒 |
| 盯視時間 | 6–8 秒 |
| QTE | 無 |
| 老婆位置 | 每次轉頭隨機換位（5 個定點） |

---

## Stage 3 — 約會

| 項目 | 內容 |
|---|---|
| 時間 | 600 秒（10 分鐘） |
| 通關條件 | 倒數結束時 realized total ≥ $30,000 → Results 畫面（勝利） |
| 失敗條件 | TIMEOUT / CAUGHT / SUSPICION（疑心值歸零） |
| 老婆轉頭間隔 | 8–12 秒 |
| 盯視時間 | 6–8 秒 |
| QTE 觸發率 | 80%（盯視 1–2 秒後觸發） |
| 疑心值 | 2 格；QTE 失敗 -1；歸零即 SUSPICION 失敗 |
| 老婆位置 | 每次轉頭隨機換位（5 個定點） |

---

## 失敗原因一覽

| 原因 | 觸發條件 |
|---|---|
| CAUGHT | 老婆轉頭後 0.5 秒內未按 Space 藏手機，或盯視/QTE 期間顯示手機 |
| TIMEOUT | 關卡計時結束但 realized total < $30,000 |
| SUSPICION | Stage 3 限定，疑心值 2 格全部耗盡 |

---

## 設計備註

- $30,000 是跨三關的「累計門檻」，不是每關各自達標
- Stage 1 從 $10,000 起步，5 分鐘內需讓 realized total 達 $30,000（三倍）難度極高
- 可考慮：每關設獨立較低門檻，或讓 $30,000 只在 Stage 3 結束才檢查
