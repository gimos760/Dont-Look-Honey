# Don't Look, Honey — 類股資訊

> 每局從 7 檔類股隨機抽取 5 檔。
> 蠟燭週期：每 **4 秒** 一根（每分鐘 15 根）。
> 起始價格：在 min–max 的 40%–60% 區間隨機取。

## 各類股特性說明

### FIN — Finance（金融）
- 低波動、無趨勢、無尖峰
- 適合保守操作，但獲利潛力低
- 每根蠟燭最多漲跌約 ±0.3%

### BIO — Biotech（生技）
- 中高波動，有輕微上升趨勢
- 每 12–13 根就有一次尖峰事件（±5–10 倍正常波幅）
- 高風險高報酬，方向難以預測

### NRG — Energy（能源）
- 中低波動、無趨勢、無尖峰
- 穩定但緩慢，適合長線持倉

### GOLD — Gold ETF（黃金）
- 低波動、有穩定上升趨勢（最強趨勢偏壓）
- 無尖峰，走勢最穩定
- 適合 Long 策略

### BTC — BTC ETF（比特幣）
- **最高波動（3%/根）**，有上升趨勢
- **尖峰機率最高（12%）**，約每 8 根觸發一次
- 最高風險，也是單筆獲利最大的類股
- 每股價格 $800–$1,800，資金需求最高

### TECH — Tech（科技）
- 中高波動，有輕微上升趨勢
- 無尖峰，走勢相對可預測
- 價格範圍大（$200–$800），適合多種策略

### AI — AI（人工智慧）
- 高波動（1.8%/根），有上升趨勢
- 尖峰機率高（10%），約每 10 根觸發一次
- 每股價格 $400–$1,200，資金需求中高

## 趨勢系統

每檔股票都有一個當前趨勢方向（漲勢 / 跌勢），決定每根蠟燭的偏壓方向。

- **趨勢偏壓幅度**固定，方向隨趨勢翻轉（漲勢用 +bias，跌勢用 -bias）
- **初始趨勢**：遊戲開始時隨機決定
- **反轉觸發條件**：出現高成交量事件時，進行反轉機率判定

---

## 趨勢反轉機率（均值回歸）

反轉只在**高成交量**事件發生時判定。

```
normalized = (現在股價 - Min) / (Max - Min)   # 0 = 在底部, 1 = 在頂部

漲勢反轉機率 = normalized          # 靠近頂部 → 反轉機率高
跌勢反轉機率 = 1 - normalized      # 靠近底部 → 反轉機率高
```

範例（GOLD，price=500，Min=300，Max=600）：
- norm = (500-300)/(600-300) = 0.67
- 若目前漲勢 → 反轉機率 67%
- 若目前跌勢 → 反轉機率 33%

---

## 高成交量事件

觸發來源（兩者獨立判定，取聯集）：
1. **尖峰事件**：必定伴隨高成交量
2. **獨立高量**：每根蠟燭按 `high_vol_chance` 獨立判定

效果：
- 成交量為正常的 **2.5–5 倍**
- 觸發趨勢反轉判定
- 圖表顯示提示：`High Vol  Trend: Up  Rev: 67%`（4 秒後消失）

---

## 尖峰事件

觸發條件：達到 `spike_chance`（每根蠟燭獨立判定）

效果：
- 方向：50% 向上 / 50% 向下（隨機，不受趨勢影響）
- 幅度：正常波幅的 **5–10 倍**
- 必定觸發高成交量 → 連帶觸發趨勢反轉判定

範例（BTC，正常波幅 3%）：尖峰觸發 → 最大漲跌 **15%–30%** 單根

---

## 邊界保護機制

當價格到達極端邊界時，強制翻轉趨勢（優先於反轉機率判定）：
- 超過 **95%** 區間上緣 → 強制切換為跌勢
- 低於 **5%** 區間下緣 → 強制切換為漲勢
